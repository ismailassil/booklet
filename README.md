# Booklet - Flipbook to PDF

A simple frontend-only tool that converts compatible public FlipHTML5 books into PDFs.

## Use

1. Open `index.html` with a local development server.
2. Paste a FlipHTML5 book URL.
3. Select **Make my PDF**.
4. Your PDF downloads directly in the browser.

## Notes

- Nothing is uploaded or stored by this page.
- If you face an CORS Error, please install the cors unblock extension and enable it, to bypass the CROS issue.
